# 11 — UX and Information Architecture

Primary navigation: Overview, Inventory, Physical Count, Cutoff, Ownership, Valuation, Exceptions, Evidence, Reconciliation, Adjustments, Audit Package, Assumptions, User Guide. Ask Gaurd is a persistent right-side drawer, not the homepage.

## Overview
Show FY2026 close, 81.4% ready, 7 blockers / $198,950, $12,450 GL difference, 80.95% PBC readiness and 91.67% source health. The most prominent panel is **Preventing Sign-Off**.

## Signature exception UX
EXC-001 shows **NetSuite Says / Physical Evidence Says / Accounting Evidence**, then transaction chain, Known/Conflicting/Missing evidence, assertions, conclusion, next action, timeline, adjustment if any, and Audit Details.

## Financial Life
A primary serial view reconstructs buy side, inventory/cycle counts, sell/deploy side and accounting. Global serial search reaches it in one click.

## Physical Count
Tabs: Year-End Count, Cycle Count History, Auditor Test Counts, Count Movements. Cycle Count History shows prior snapshots/counts/variances/recounts/adjustments/next count without implying auditor reliance.

## Reconciliation
Tabs: Financial; Procurement Match; Commercial Chain; Serial Integrity. Native NetSuite control status and close-control status are separate.

## Evidence
Evidence Center and clickable graph with SUPPORTS, CONFLICTS_WITH, REQUIRED_FOR, CORROBORATES. Deep provenance is under Audit Details, not cluttering primary decision surfaces.

UX hierarchy: What matters → Why it matters → What supports it → What happens next.
